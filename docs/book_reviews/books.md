# Books I liked

### [Programming Massively Parallel Processors: A Hands-on Approach](https://www.amazon.com/Programming-Massively-Parallel-Processors-Hands/dp/0124159923)
*David B. Kirk, Wen-mei W. Hwu*
> This book, Programming Massively Parallel Processors by Wen-mei W. Hwu and David B. Kirk, had been sitting on my shelf for quite a while before I finally made time to read it.he best part of it is the simplicity of the text makes complex ideas accessible without oversimplifying.Even if you don’t write CUDA code, this book is crucial for every ML/AI engineer. Understanding how parallel processors work helps develop a deeper appreciation of what happens under the hood when running models. It also helps you to write better, more efficient code—whether in PyTorch, TensorFlow, or any other framework that relies on parallelism.Some key points that it covers:
 - Clear explanations of GPU architecture and memory layout and why they matter
- Core parallel programming concepts like threads, synchronization, tiling and memory access
- Clear use case based examples to explain concepts
- Techniques to break down problems so they effectively run on thousands of cores

Reading this book has shifted how I think about designing and optimizing AI code for parallel execution. It’s a meaningful read for anyone wanting more than a surface-level understanding of their tools and hardware.
