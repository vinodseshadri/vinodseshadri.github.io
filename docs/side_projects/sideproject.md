# Open Source Projects

I open-source projects that reflect the kind of systems I build professionally — production-shaped, not just notebooks. Code for all of these is on [GitHub](https://github.com/vinodseshadri).

### [AWS Serverless Resume Pipeline](https://github.com/vinodseshadri/aws-serverless-resume-pipeline)
*A fully cloud-native, event-driven document processing system.*

**Stack:** AWS Lambda, Textract, Comprehend, Cognito, S3, SQS

A serverless microservices architecture that extracts structured insights from resumes, with a custom Chat UI backed by **AWS Lex** for interactive querying. Mirrors the conversational AI and event-driven cloud architecture patterns I use professionally.

### [Deep Anomaly Analytics Engine](https://github.com/vinodseshadri/deep-anomaly-analytics-engine)
*Advanced industrial monitoring for time-series sensor data.*

**Stack:** Keras (LSTM Autoencoders), MongoDB, Python, Plotly

Detects anomalies in real-time sensor streams from PLCs. Built on the same univariate/multivariate time-series and IoT anomaly detection techniques I've applied to industrial predictive-maintenance work.

### [NLP Resume Parser](https://github.com/vinodseshadri/nlp-resume-parser)
*Privacy-first Named Entity Recognition engine.*

**Stack:** SpaCy, Flask, PDFMiner

A custom-trained NER model for high-precision extraction of skills and certifications, designed for secure, local processing of sensitive candidate data — no data leaves the system.
