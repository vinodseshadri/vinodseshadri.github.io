LeetCode Patterns

Read the question → spot the signal → pick the pattern. Always: state brute force + complexity first, then optimize. Edge cases: empty, single, duplicates, negatives, overflow.
Constraints → target complexity
n ≤ 20: 2^n / backtracking / bitmask · n ≤ 500: n³ · n ≤ 5×10³: n² (2D DP) · n ≤ 10⁵–10⁶: n log n  or  n (sort, heap, window, hash) · n ≥ 10⁹: log n / math
Keyword → pattern
"sorted" → binary search / two pointers · "contiguous subarray/substring" → window / prefix sum · "top K", "Kth" → heap · "all combinations/permutations" → backtracking · "shortest path (unweighted)" → BFS · "min/max/count ways" → DP · "prerequisites/order" → topo sort · "connected/groups" → union-find / DFS
1Hash map / setO(n)
lookup, count
Use when
Need O(1) lookup, frequency, duplicates, complement, grouping
Idea & problems
Store seen value → index / count; check target-x before insert. Two Sum, Group Anagrams, Longest Consecutive Sequence, Contains Duplicate, Valid Anagram
2Two pointersO(n)
opposite ends / read-write
Use when
Sorted array, pair/triple with target, palindrome, in-place removal or partition
Idea & problems
l=0,r=n-1: move the side that fixes the inequality. Read/write: w writes, r scans. 3Sum, Container With Most Water, Valid Palindrome, Move Zeroes, Remove Duplicates, Trapping Rain Water
3Sliding windowO(n)
variable / fixed
Use when
Contiguous subarray/substring; longest, shortest, "at most K", fixed size k
Idea & problems
Expand r; while invalid, shrink l; update best. Track counts in dict. Longest Substring w/o Repeating, Minimum Window Substring, Longest Repeating Char Replacement, Max Avg Subarray, Permutation in String
4Prefix sumO(n)
+ hash of prefixes
Use when
Range sum queries; "subarray sum equals K" (negatives allowed, so window fails)
Idea & problems
pre[i]=pre[i-1]+a[i]; count of pre-K seen so far. Subarray Sum Equals K, Product of Array Except Self, Range Sum Query, Continuous Subarray Sum
5Fast & slow pointersO(n)
Use when
Linked-list cycle, middle node, nth from end, happy number
Idea & problems
slow=next, fast=next.next; meet ⇒ cycle; reset one to head to find entry. Linked List Cycle I/II, Middle of List, Remove Nth From End, Palindrome LL, Happy Number
6Linked-list opsO(n)
Use when
Reverse, merge, reorder, detect, insert at head
Idea & problems
Dummy head; iterative reverse prev,cur. Reverse LL, Merge Two Sorted Lists, Reorder List, Add Two Numbers, LRU Cache
7Binary searchO(log n)
on array / on answer
Use when
Sorted or rotated array; "minimum X such that feasible" (monotonic true/false)
Idea & problems
while l<=r: mid; shrink to the half that can hold the answer; for "min feasible": l=mid+1 if !ok else r=mid. Search Rotated Array, Find Min in Rotated, Koko Eating Bananas, Capacity to Ship, Median of Two Sorted Arrays
8StackO(n)
monotonic stack
Use when
Matching/nesting; "next greater/smaller"; largest rectangle; evaluate expressions
Idea & problems
Push index; pop while top breaks order → answer for popped. Valid Parentheses, Daily Temperatures, Next Greater Element, Largest Rectangle in Histogram, Min Stack, Decode String
9Heap / top-KO(n log k)
two heaps, k-way merge
Use when
Top K / Kth largest, running median, merge K sorted, scheduling by priority
Idea & problems
Min-heap of size K for top-K largest; max-heap + min-heap for median. Kth Largest, Top K Frequent, Merge K Sorted Lists, Find Median from Data Stream, Task Scheduler, K Closest Points
10IntervalsO(n log n)
Use when
Merge, insert, overlap, meeting rooms, minimum removals
Idea & problems
Sort by start (or end for greedy); compare cur.start ≤ last.end. Rooms: heap of end times. Merge Intervals, Insert Interval, Meeting Rooms I/II, Non-overlapping Intervals
11BFSO(V+E)
queue, level order
Use when
Shortest path in unweighted graph/grid; level-by-level; multi-source spread; min steps
Idea & problems
Queue + visited; process by level (for _ in range(len(q))). Multi-source: enqueue all sources first. Binary Tree Level Order, Rotting Oranges, Word Ladder, Shortest Path in Binary Matrix, 01 Matrix
12DFSO(V+E)
trees, graphs, grids
Use when
Explore all; connected regions; tree properties (depth, path, validity)
Idea & problems
Recurse with base case; mark visited; return value up (postorder) or pass state down. Number of Islands, Max Depth, Validate BST, Lowest Common Ancestor, Path Sum, Clone Graph, Invert Tree
13BacktrackingO(2ⁿ) / O(n!)
Use when
Generate ALL combinations, permutations, subsets, partitions; constraint puzzles
Idea & problems
choose → recurse → un-choose; prune early; sort + skip dupes. Subsets, Permutations, Combination Sum, Word Search, N-Queens, Generate Parentheses, Palindrome Partitioning
14Topological sortO(V+E)
Use when
Dependencies, prerequisites, build order, detect cycle in directed graph
Idea & problems
Kahn: indegree map, queue of zeros; if visited < V ⇒ cycle. Course Schedule I/II, Alien Dictionary, Minimum Height Trees
15Union-Find~O(α(n))
Use when
Connected components, merging groups, cycle in undirected graph, dynamic connectivity
Idea & problems
parent[] with path compression + union by rank. Number of Provinces, Redundant Connection, Accounts Merge, Graph Valid Tree
16DijkstraO(E log V)
weighted shortest path
Use when
Non-negative edge weights; "min cost/time/effort" path
Idea & problems
Min-heap of (dist,node); skip stale entries. Negative edges or "at most K stops" → Bellman-Ford. Network Delay Time, Path With Minimum Effort, Cheapest Flights Within K Stops
17Dynamic programmingO(states×trans)
1D / 2D / knapsack
Use when
"Min / max / count ways / can we"; overlapping subproblems; choices at each step
Idea & problems
Define state, transition, base, order; then compress space. 1D: Climbing Stairs, House Robber, Coin Change, LIS, Word Break · 2D: LCS, Edit Distance, Unique Paths · Knapsack: Partition Equal Subset Sum, Target Sum
18GreedyO(n log n)
Use when
Local best is provably global best; sort then sweep; jumps, gas, scheduling
Idea & problems
Sort by the right key; keep running best; prove with an exchange argument. Jump Game I/II, Gas Station, Assign Cookies, Partition Labels, Best Time to Buy/Sell Stock
19TrieO(L)
Use when
Prefix search, autocomplete, word dictionary, many words on a grid
Idea & problems
Node = dict of children + end flag. Implement Trie, Add & Search Word, Word Search II
20Matrix / gridO(m·n)
Use when
2D array in place: rotate, spiral, zero rows/cols; neighbors via direction arrays
Idea & problems
Rotate = transpose + reverse rows; spiral = 4 shrinking bounds; dirs=[(1,0),(-1,0),(0,1),(0,-1)]. Rotate Image, Spiral Matrix, Set Matrix Zeroes, Search a 2D Matrix
21Bit manipulationO(n)
XOR
Use when
Find the odd one out; count bits; power of two; subsets via masks
Idea & problems
a^a=0, n&(n-1) clears lowest set bit. Single Number, Missing Number, Number of 1 Bits, Counting Bits
22Cyclic sortO(n)
values in 1..n
Use when
Array of 1..n; find missing / duplicate in O(1) extra space
Idea & problems
Swap each value to index v-1; scan for mismatch. Find All Duplicates, First Missing Positive, Find the Duplicate Number
Pick between look-alikes
Pick between look-alikes: Window vs prefix sum — negatives in the array ⇒ prefix sum.   BFS vs DFS — shortest steps ⇒ BFS; explore all / recurse on tree ⇒ DFS.   DP vs greedy — if a local choice can be wrong later ⇒ DP.   Heap vs sort — only need top K ⇒ heap (n log k).   Backtracking vs DP — list every answer ⇒ backtracking; count/optimize ⇒ DP.   Interview flow: clarify → brute force → pattern → code → dry-run on a small case → complexity.
